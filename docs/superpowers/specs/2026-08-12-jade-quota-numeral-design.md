# 青玉灵数与大庚剑阵融合设计

## 目标

让七日余量数字不再像覆盖在剑阵上的白色界面文字，而像由阵眼灵力凝成的法宝读数。保持已经确认的字号与位置，不调整人物、阵盘布局、账户余额区和交互逻辑。

## 视觉方向

采用“青玉灵数”作为唯一显著强化点。数字保留清晰的西文数字结构，但降低 Didot 式的强烈粗细反差，优先使用 `Baskerville`、`Times New Roman`、`Georgia` 的本机衬线回退组合。数字材质由月白高光、青玉主体和极少量淡金反光构成；不使用纯白填色或大面积霓虹外发光。

数字效果分为三层：

1. 细暗青描边，将笔画从复杂背景中收住。
2. 月白到青玉再到淡金的纵向渐变，模拟半透明玉质与阵法反光。
3. 一层低透明青色辉光，与点亮剑身共用同一组状态色。

阵眼后方增加小范围椭圆聚光，但必须弱于数字本身，不增加新的圆环或装饰纹样。

## 额度状态联动

卡片继续使用已有的 `data-used-state`：

- 充盈状态：月白青玉为主，淡金只作为下缘反光；剑身呈清亮青绿。
- 警戒状态：降低月白比例，提高青玉与暖金比例；剑身辉光同步转暖。
- 枯竭状态：主体转为暗金青铜，保留一丝青光维持法宝属性；剑身同步减弱、转暗。

数字、阵眼聚光与点亮剑身通过卡片级 CSS 变量共享颜色，避免三套独立色彩造成割裂。未点亮剑仍保持低透明暗青，不跟随高亮色增强。

## 动效与可读性

数字不新增持续位移或跳动，仅允许非常轻微的材质明暗呼吸；切换额度时沿用现有数字过渡。`prefers-reduced-motion` 下停止材质呼吸，但保留静态渐变、描边与状态颜色。

80%、45%、15% 均使用同一字号和阵眼位置。渐变不能降低小尺寸数字的边缘清晰度，人物面部区域不得新增光效覆盖。

## 验收

- 三档额度下，数字与点亮剑身共享对应的青玉或金青色调。
- 数字不再呈纯白平面字，也没有明显霓虹灯质感。
- 15% 的两位数字、45% 与 80% 的三字符组合都能完整落在阵眼内。
- 减少动态效果模式下无持续呼吸动画。
- 原有 `setUsed()`、三个演示按钮、解锁按钮和美元余额显示保持不变。
